## Welcome

**BetbetMiro Extension** is a CloudStream extension repository separated into multiple channels so providers, documentation, and build output can be managed more clearly.

The `Welcome` branch only serves as the entry page and navigation hub. For installation, technical documentation, or provider usage, choose one of the channels below.

---

## Choose a Channel

| Shortcode | Branch | Channel | Purpose |
|---|---|---|---|
| `BME-REPO` | [`master`](https://github.com/sad25kag/BetbetMiro-Extension/tree/master) | Regular Channel | Regular providers for anime, donghua, drama, movies, and multi-source providers |
| `BME-NFSW` | [`main`](https://github.com/sad25kag/BetbetMiro-Extension/tree/main) | NSFW / 18+ Channel | NSFW, 18+, age-restricted, or region-restricted provider channel |

---

## Regular Channel — `BME-REPO`

Use branch `master` for the regular channel.

**Branch:**

```text
https://github.com/sad25kag/BetbetMiro-Extension/tree/master
```

**CloudStream repository URL:**

```text
https://raw.githubusercontent.com/sad25kag/BetbetMiro-Extension/master/repo.json
```

**One-click install:**

```text
cloudstreamrepo://raw.githubusercontent.com/sad25kag/BetbetMiro-Extension/master/repo.json
```
