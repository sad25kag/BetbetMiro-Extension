## Selamat Datang

**BetbetMiro Extension** adalah repository ekstensi CloudStream yang dipisahkan menjadi beberapa channel agar provider, dokumentasi, dan output build lebih mudah dikelola.

Branch `Welcome` ini hanya berfungsi sebagai halaman awal dan navigasi. Untuk instalasi, dokumentasi teknis, atau penggunaan provider, pilih salah satu channel di bawah.

---

## Pilih Channel

| Shortcode | Branch | Channel | Fungsi |
|---|---|---|---|
| `BME-REPO` | [`master`](https://github.com/sad25kag/BetbetMiro-Extension/tree/master) | Regular Channel | Provider reguler untuk anime, donghua, drama, movie, dan multi-source provider |
| `BME-NFSW` | [`main`](https://github.com/sad25kag/BetbetMiro-Extension/tree/main) | NSFW / 18+ Channel | Provider khusus NSFW, 18+, age-restricted, atau sumber dengan pembatasan usia/wilayah |

---

## Regular Channel — `BME-REPO`

Gunakan branch `master` untuk channel reguler.

**Branch:**

```text
https://github.com/sad25kag/BetbetMiro-Extension/tree/master
```

**Repository URL untuk CloudStream:**

```text
https://raw.githubusercontent.com/sad25kag/BetbetMiro-Extension/master/repo.json
```

**One-click install:**

```text
cloudstreamrepo://raw.githubusercontent.com/sad25kag/BetbetMiro-Extension/master/repo.json
```

## NSFW / 18+ Channel — `BME-NFSW`

Gunakan branch `main` hanya jika Anda memang ingin memakai channel NSFW / 18+.

**Branch:**


**Repository URL untuk CloudStream:**


**One-click install:**


> Channel ini dapat mengarah ke sumber NSFW, 18+, age-restricted, atau sumber dengan pembatasan wilayah. Pengguna bertanggung jawab penuh atas penggunaan channel ini sesuai usia, aturan, dan hukum yang berlaku di wilayah masing-masing.

---

## Catatan Navigasi

- Branch `Welcome` hanya berisi halaman awal dan petunjuk navigasi.
- Dokumentasi teknis berada di masing-masing branch channel.
- Provider, parser, metadata, dan output build dikelola terpisah sesuai channel.
- Pilih `master` untuk penggunaan reguler.
- Pilih `main` hanya untuk channel NSFW / 18+.

---

## Disclaimer

Repository ini tidak menyimpan, meng-host, atau mendistribusikan konten video apa pun.

Semua konten berasal dari sumber pihak ketiga yang tersedia di internet. Repository ini hanya menyediakan parser dan integrasi provider untuk CloudStream.

Pemilik repository tidak berafiliasi dengan CloudStream maupun sumber pihak ketiga yang digunakan oleh provider.
